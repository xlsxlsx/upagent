# Code Execution Tool

## 能力

- 运行代码片段：验证算法、库用法、正则等局部逻辑
- 运行完整程序：确认「可运行」这条质量底线（Rule 2）
- 运行测试：单元 / 集成 / E2E 套件
- 复现 Bug：用最小可复现示例定位根因

## 使用规范

- 任何代码在标记完成前必须实际运行过；「看起来对」不算验证。
- 用项目自身的环境与运行方式执行（如 `uv run ...`），不混用全局环境。
- 复现 Bug 时先做最小化：剥离无关代码，锁定触发条件。
- 运行结果如实反映在报告中，包括失败输出。

## 限制（对齐 safety_policy.md）

- 不运行来源不可信的代码。
- 不运行会修改系统环境、删除文件、访问生产数据的代码，除非用户确认。
- 长时间运行的程序放后台并设置超时，不无限等待。
- 执行含网络调用的代码前确认目标与费用（付费 API 需用户确认）。
