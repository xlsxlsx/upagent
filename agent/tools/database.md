# Database Tool

## 能力

- 执行 Schema：建表、索引、约束（通过迁移脚本）
- 执行迁移：初始化与增量变更，支持回滚
- 查询验证：核对数据写入是否符合预期
- 准备测试数据：为集成测试与 E2E 测试灌入数据

## 使用规范

- Schema 变更**只走迁移脚本**，禁止直接手改数据库结构。
- 迁移脚本必须可重复执行（幂等或带版本控制）且有回滚方案。
- 查询验证优先只读操作；写操作在事务里做，出错回滚。
- 测试数据使用构造数据，禁止复制真实用户数据。

## 限制（对齐 safety_policy.md）

- 禁止 `DROP TABLE` / `TRUNCATE` / 无 WHERE 的 `DELETE`、`UPDATE`，除非用户明确确认。
- 破坏性迁移（删列、改类型）需 Supervisor/用户确认并备份先行。
- 数据库连接凭证走环境变量，禁止写入代码或文档。
- 生产数据库操作必须先获用户确认。
