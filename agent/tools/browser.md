# Browser Tool

## 能力

- 打开页面：验证前端功能、检查渲染结果
- 交互操作：点击、输入、滚动，走通用户流程（配合 E2E 测试）
- 截图取证：为测试报告与 Bug 记录提供证据
- 查资料：检索文档、验证 API 用法、确认依赖的官方说明

## 典型用途

| 场景 | 使用角色 |
| --- | --- |
| E2E 测试执行与截图 | Tester |
| 前端页面自测（三态、响应式） | Frontend Engineer |
| 查官方文档、核对最新 API | 各工程师 |
| 核查依赖已知漏洞（CVE 公告） | Security Auditor |

## 使用规范

- 验证页面时优先走真实用户路径，不只看首屏。
- 发现问题立即截图留证，附在 Bug 记录或测试报告中。
- 引用外部资料时优先官方文档，注明来源。

## 限制

- 不向外部网站提交项目代码、密钥或用户数据。
- 不在网页上执行登录真实账户等涉及用户凭证的操作，除非用户明确授权。
- 不下载执行不可信内容。
