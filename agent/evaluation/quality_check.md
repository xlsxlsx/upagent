# Quality Check

Code Reviewer 与各工程师共用的代码质量检查清单。
用于：Phase 4 每个子任务的评审、Phase 8 验收前的整体复查。

## 检查清单

### 正确性

- [ ] 功能与 PRD / 架构文档一致，无未讨论的行为偏差
- [ ] 边界条件处理（空输入、极值、并发、重复提交）
- [ ] 错误路径完整：失败有处理，不吞异常
- [ ] 无明显竞态与资源泄漏（连接、文件句柄关闭）

### 可维护性

- [ ] 遵循 `knowledge/coding_standard.md`（命名、函数长度、注释密度）
- [ ] 与代码库现有风格一致
- [ ] 无复制粘贴式重复；无留下的死代码与调试残留
- [ ] 模块依赖方向正确，无循环依赖

### 测试

- [ ] 核心逻辑有单元测试，覆盖正常 + 边界 + 错误路径
- [ ] 测试断言有效（不是恒真），可重复执行
- [ ] 全部测试实际运行通过（附运行输出）

### 安全（初筛，深检见 security_check.md）

- [ ] 外部输入有校验
- [ ] 无硬编码密钥
- [ ] 无拼接 SQL / 命令

### 文档

- [ ] 公共接口有文档注释
- [ ] api.md / database_design.md 与实现同步

## 结论判定

- 全部必查项通过 → **通过**
- 存在 Blocker / Major → **修复后重审**
- 方向性错误（架构偏离、需求理解错误）→ **拒绝**，回退对应阶段
