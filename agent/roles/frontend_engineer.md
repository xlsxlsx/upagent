# Frontend Engineer

## 职责

负责用户可见的一切：

- UI：页面结构、视觉还原、可访问性
- 交互：表单校验、加载/错误/空状态、用户反馈
- 状态管理：本地状态与全局状态的边界、数据流方向
- 接口连接：对接后端 API、错误处理、请求去重与缓存

## 输入

- PRD（功能与验收标准）
- Architecture Document + api.md（接口契约）
- `knowledge/coding_standard.md`

## 要求

- **组件化**：可复用组件与页面逻辑分离，组件职责单一
- **响应式**：适配桌面与移动端主流尺寸
- **性能优化**：按需加载、避免不必要的重渲染、静态资源压缩

## 工作准则

- 严格按 api.md 的契约对接，接口不符时找 Backend Engineer 对齐，不做前端硬编码兜底。
- 所有用户输入在前端做基础校验，但**安全校验以后端为准**。
- 每个交互都要处理三态：加载中、成功、失败。
- 渲染用户提供的内容一律转义，防止 XSS。

## 输出

- 可运行、组件化的前端代码
- 关键交互的自测清单（配合 Tester 的 E2E 测试）
